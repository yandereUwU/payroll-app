# Система расчёта заработной платы сотрудников

Настольное приложение для автоматизации расчёта заработной платы, ведения кадрового учёта и формирования отчётности. Разработано в рамках дипломной работы.

---

## Описание

Приложение предназначено для малых и средних организаций и позволяет автоматизировать процесс начисления заработной платы сотрудникам. Система обеспечивает хранение данных о сотрудниках, учёт отработанных дней и премий, расчёт налоговых удержаний, формирование истории начислений и экспорт отчётов в Excel.

---

## Функциональные возможности

- **Авторизация** пользователей с разграничением прав доступа
- **Ролевая модель**: администратор, бухгалтер, руководитель, сотрудник
- **Управление пользователями** — создание, удаление, назначение ролей
- **Управление сотрудниками** — добавление, просмотр, удаление
- **Управление должностями** — добавление и удаление
- **Расчёт заработной платы** с учётом:
  - оклада (дневной ставки)
  - отработанных дней
  - премии
  - налога на доходы физических лиц (13%)
- **Просмотр истории начислений** по каждому сотруднику
- **Формирование отчётов** с фильтрацией по периоду
- **Экспорт данных в Excel** (.xlsx)

---

## Роли пользователей   
Администратор - Полный доступ: управление пользователями, сотрудниками, должностями, расчёт зарплаты, отчёты
Бухгалтер - Работа с сотрудниками, расчёт зарплаты, просмотр и формирование отчётов
Руководитель - Просмотр начислений всех сотрудников, закрытие расчётных периодов
Сотрудник- Просмотр своих данных и истории начислений (личный кабинет)

## Особенности реализации
- Локальная база данных SQLite — не требуется сервер
- Автоматическое создание таблиц при первом запуске
- Ролевая модель доступа на уровне интерфейса
- Автоматический расчёт налога (13%)
- Сохранение истории начислений с привязкой к периоду
- Закрытие расчётных периодов (блокировка изменений)
- Журнал аудита действий пользователей
- Кроссплатформенность: Windows, macOS, Linux

## Эффективность
Приложение сокращает время расчёта заработной платы для штата до 50 сотрудников с 3–4 часов до 20–30 минут, полностью исключая арифметические ошибки.
